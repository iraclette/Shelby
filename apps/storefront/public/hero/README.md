Drop a real photo here as `hero.jpg` and the homepage hero picks it up automatically —
no code changes needed (see `hasHeroPhoto` in `src/app/page.tsx`).

Suggested shot: something moody and dark that fits the ink/brass palette — a knife on
leather, a store shelf, whatever's on hand. The gradient + grain overlay (`.atmosphere`
in `globals.css`) sits on top of it for text contrast, so it doesn't need to be
pre-darkened.

Recommended: 1920×1080 or wider, JPG or WebP, under ~500KB.
